# 0.1.0-alpha.1

Initial standalone preview of Mac Input Guard.

- Manual physical-input protection with a visible desktop and independent password.
- Bounded 12-second preview and fail-open parent/worker health monitoring.
- Per-user portable storage and an explicit local compatibility review.
- Optional background login startup without automatic protection.
- Universal macOS build, local installation, uninstall, and distribution scripts.
- Optional Codex workflow guidance for browser and Finder interoperability.

This preview does not establish compatibility with every Mac or automation tool.
Ad-hoc development artifacts are not a notarized public release. Signing,
notarization, fresh-machine testing, and actual hardware acceptance must be
reported separately before promoting a binary as a general release.
